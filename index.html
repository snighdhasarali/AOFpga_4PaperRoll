FPGA Forklift Accessibility Analyzer

Real-time neighborhood analysis using streaming Verilog architecture

⚡ Project Overview

This project implements a hardware-accelerated warehouse grid analyzer using FPGA technology. Each processing cycle analyzes incoming cells in real-time to determine forklift accessibility based on neighborhood occupancy patterns.

Core Concepts: The system uses a streaming architecture that processes data sequentially without storing the full matrix in memory. A sliding window analyzes 3x3 neighborhoods using shift-register buffering, making it highly efficient for FPGA implementation.

Accessibility Rule: A cell is marked ACCESSIBLE when its value is 1 (active) AND it has fewer than 4 neighboring active cells. This ensures optimal forklift navigation paths with sufficient clearance.

⚙️ Architecture Comparison

Golden Reference Model

  • Software-style full matrix processing
  • Stores entire grid in memory
  • Random access to all cells
  • Simple implementation
  • Higher memory requirements
  • Used for verification

Streaming FPGA Model

  • Hardware-efficient sequential processing
  • Shift-register buffering (3 rows only)
  • Sliding window neighborhood analysis
  • Pipelined architecture
  • Minimal memory footprint
  • Real-time FPGA implementation
